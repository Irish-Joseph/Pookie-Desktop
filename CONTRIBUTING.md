# Contributing

Issues and pull requests are welcome. Fork the repository and open a pull request against `main`; only the repository owner merges changes. Keep changes focused, explain their privacy effect, and include a reproducible test or manual verification steps. Run `npm run check`, `npm test`, `cargo test --manifest-path src-tauri/Cargo.toml`, and `npm run tauri build` before proposing a release. Do not commit API keys, local settings, saved chat, screenshots, or generated bundles. See [development](docs/development.md).
