## Caption

Meet Pookie 👋 A tiny robot on my Windows desktop because apparently my tabs needed a chaperone.

I built this in my spare time as an open-source learning project. It combines an animated Tauri desktop companion with React, Rust, and local Ollama models. You can chat with it or choose to preview a window or screen capture before asking a vision model about it.

It is an early build, and I am sharing the code and the setup steps so others can try it and contribute. Pull requests are welcome; I review and merge changes myself.

Code and local setup: github.com/Irish-Joseph/Pookie-Desktop
