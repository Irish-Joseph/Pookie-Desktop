# Ollama model setup

Install [Ollama](https://ollama.com/download/windows), start it, and run `ollama list` to see local models. To try fast text chat, run `ollama pull qwen2.5:0.5b`. To ask about screenshots, run `ollama pull qwen3-vl:2b-instruct`. Select the downloaded model in Pookie Settings and use **Test connection**. Pookie discovers models through Ollama `/api/tags` and reads `/api/show` capabilities. Only models reporting `completion` are offered for chat, and screenshots require `vision`. The small text model is useful for a smoke test but may give shallow answers. Downloads are initiated by the user outside Pookie. See the step-by-step [local setup](../README.md#run-locally-on-windows).
